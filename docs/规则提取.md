# 规则提取

## 概述

规则提取是 B2RScan 的核心功能之一，负责从各种 SAST 工具中提取安全规则并将其转换为统一的 xCPG-IR 格式。

## 支持的 SAST 工具

目前支持以下 SAST 工具的规则提取：

1. **CodeQL** - GitHub 的语义代码分析引擎
2. **Semgrep** - 快速静态分析工具

## 工作原理

规则提取过程遵循以下步骤：

1. **分析 SAST 工具结构** - 理解工具的目录结构和规则组织方式
2. **定位规则文件** - 根据文件扩展名和目录模式查找规则文件
3. **解析规则** - 使用特定解析器提取规则信息
4. **转换为 xCPG-IR** - 将提取的规则映射到统一的中间表示
5. **验证和去重** - 验证 IR 格式并去除重复规则

## 使用方法

### 基本用法

```python
from b2rscan.task.rule_extraction import RuleExtractor

# 初始化提取器
extractor = RuleExtractor()

# 提取规则
rules = extractor.extract_rules("codeql", "/path/to/codeql/rules")
```

### 配置选项

可以传递选项来自定义提取过程：

```python
options = {
    "include_patterns": ["**/*.ql"],      # 包含的文件模式
    "exclude_patterns": ["test/**/*.ql"], # 排除的文件模式
    "max_depth": 3                        # 最大搜索深度
}

rules = extractor.extract_rules("codeql", "/path/to/codeql/rules", options)
```

## xCPG-IR 格式

提取的规则将被转换为以下 xCPG-IR 格式：

```json
{
  "id": "规则唯一标识符",
  "name": "规则名称",
  "description": "规则描述",
  "severity": "严重性等级 (low|medium|high|critical)",
  "sources": ["数据源点列表"],
  "sinks": ["数据汇点列表"],
  "sanitizers": ["净化函数列表"],
  "validators": ["验证函数列表"],
  "meta": {
    "额外元数据"
  }
}
```
